# Nonpositive first band coefficient: elementary source localization

Read [the appendix terminology](../../appendix.md#terminology) before this technical lemma. Its variables are local to this document.

Let P>1,0<Q<1,0<a<b<xi,l>0,k>0, and suppose R=r(1+r)+k(r+l)(r-a)(r-b) has strictly positive coefficients. Put

d=b-a,L=a+l,M=b+l,rho=M/L>1,
A=a(1+a),G=a+b+2ab,j(a)=Q-(P-1)a.

For the compact central-band operator, the first coefficient has the same sign as

2M A+L(G-d j(a))-k d^2 L^2.  (1)

Positive coefficients of R give R'(a)=1+2a-kLd>0, so

k d^2 L<d(1+2a)=G-2A.

Consequently (1) is strictly larger than

L[2A(rho+1)-d j(a)].

Therefore **C1<=0 forces**

d j(a)>2a(1+a)(rho+1).

In particular j(a)>0, hence a<Q/(P-1). Since j(a)<Q<1 and rho+1>2, this also gives

d>4a(1+a)/Q>4a(1+a),
b>a+4a(1+a)/Q>5a+4a^2.
