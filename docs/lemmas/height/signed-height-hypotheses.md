# Signed metric scope: the central height witness is necessary

Read [the appendix terminology](../../appendix.md#terminology) before this technical lemma. Its variables are local to this document.

The signed metric height theorem is used on actual linked
sources whose original-x D/C root word is DCCDDC. Its numerical
E-placement description must not be treated as an unconditional
equivalence to that root word.

In particular, C having roots

```math
-1\lt\gamma_1\lt\gamma_2\lt0\lt r_3\lt\gamma_3
```

and E having placements

```math
\epsilon_-\lt\gamma_1,\qquad\epsilon_+\lt\gamma_3
```

does not by itself force two real central D roots. The inherited
the earlier proof wording of the metric theorem used the word “equivalently”
there; the precise import retains the actual DCCDDC hypothesis.
The earlier proof files are unchanged.

The smaller-gap master has the additional actual-source HEIGHT witness

```math
0\lt c_1\lt V(y),\qquad \gamma_1\lt p(y)\lt\gamma_2.
```

For the signed E placement, E is positive throughout that central
C-negative interval. Hence D is positive at both C poles, but the
positive height V(y)=uD/C forces D(y)<0. The cubic therefore has two
central simple D roots in the generic row. If E(gamma3)<0, D(r3)>0
and D(gamma3)<0 force its third root between r3 and gamma3.
These three roots exhaust its degree and give precisely the actual
original-x word DCCDDC.

Thus the signed metric theorem is validly applied in the new master.
The correction removes a false sufficient-condition shortcut, not any
necessary part of its proof. A positive independently fitted central
curve is not substituted for the actual HEIGHT witness.
